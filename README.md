# 의료분쟁 사례집 편집기 v1.1 (의사편)

병원 의료분쟁 사례를 팀 단위로 기록·정리하고, 사례집 형태의 문서로 발행하기 위한 웹 애플리케이션입니다. 여러 담당자가 실시간으로 같은 사례를 공유하고, PDF를 올리면 규칙 기반 또는 **내 컴퓨터의 로컬 AI(LM Studio)** 로 항목을 자동으로 채워 주며, 완성된 사례집은 PDF·Word로 바로 발행할 수 있습니다. 등록된 사례를 바탕으로 **통계**를 확인하고, 원내에서 자주 문의 되는 내용은 **FAQ**에서 찾아볼 수 있습니다.

---

## 왜 만들었는가

의료분쟁 사례를 사례집으로 묶어 내는 작업은, 보통 여러 담당자가 각자 다른 형식으로 정리한 문서를 취합·재정리하는 데 많은 시간이 듭니다. 이 프로그램은 다음을 목표로 합니다.

1. **입력 형식을 통일**하여 취합 시 재작업을 줄인다.
2. **PDF에서 초안을 자동으로 뽑아내되**, 민감한 문서 특성을 감안해 **로컬에서만 처리되는 AI(선택 사항)** 로 외부 유출 없이 처리할 수 있게 한다.
3. **발행 직전까지 사람이 검토**하는 구조를 유지한다 — 자동화는 초안을 만드는 단계까지이며, 저장 전 검토는 항상 사람이 합니다.

## 핵심 기능

| 기능 | 설명 |
|---|---|
| 실시간 공유 편집 | 로그인한 팀원끼리 새로고침 없이 같은 사례 목록을 함께 보고 수정합니다. |
| 로그인·권한 | 관리자가 만든 이메일 계정으로 로그인합니다. 작성자 본인 사례만 수정·삭제할 수 있도록 제한됩니다. |
| PDF 자동 인식 (규칙 기반) | 「①사건 개요 ②주요 쟁점 ③결과 ④예방 포인트」 형식의 PDF를 구간별로 나눠 폼에 채웁니다. |
| PDF 자동 인식 (로컬 AI, 선택) | LM Studio로 내 PC에서만 동작하는 AI에 문서를 보내 항목을 더 유연하게 채웁니다. 문서 내용은 인터넷 외부 서버로 나가지 않습니다. |
| 개인정보 1차 마스킹 | PDF 텍스트 추출 직후 주민등록번호·전화번호·이메일·병록번호·생년월일 패턴을 자동으로 가립니다. (완전하지 않으므로 저장 전 반드시 재검토) |
| 공식 사례집 서식 | 환자 정보, 기관별 타임라인, 환자·의료기관 양측 쟁점, 의학적 판단, 손해배상 신청액/조정결과 등 사례집 수준의 항목을 지원합니다. |
| 발행 (PDF/Word) | 진료과별로 묶인 미리보기를 인쇄(PDF 저장)하거나 Word(.doc)로 내보냅니다. |
| 통계 | 등록된 사례를 연도·진료과·처리기관별로 집계하고, 배상 발생 건수·배상률을 확인합니다. |
| FAQ | 법무지원팀으로 자주 문의되는 질문을 검색·열람할 수 있습니다. (일반 안내이며 개별 법률자문이 아닙니다.) |
| 작업 파일 백업 | JSON으로 내보내고, 다른 사람의 파일을 불러와 최신 수정 시각 기준으로 병합할 수 있습니다. |

## 기본 사용 방법

### 로그인

1. 배포된 웹 주소로 접속합니다.
2. 관리자(또는 IT 담당)가 알려 준 **이메일·비밀번호**로 로그인합니다.
3. 회원가입 화면은 없습니다. 계정이 없으면 관리자에게 발급을 요청하세요.

### 화면 구성 (상단 메뉴)

| 메뉴 | 용도 |
|---|---|
| **통계** | 접수·배상 관련 집계와 연도/진료과/처리기관별 현황 |
| **사례 관리** | 사례 등록·수정·삭제, PDF 불러오기, 작업 파일 내보내기/가져오기 |
| **사례집 미리보기 · 발행** | 진료과별 사례집 형태 확인, PDF(인쇄) / Word 발행 |
| **FAQ** | 자주 묻는 질문 검색·열람 |

### 사례 관리 탭

- **새 사례 등록**: 빈 양식에 직접 입력합니다.
- **PDF에서 AI로 서식 불러오기**: PDF를 선택하면 초안이 폼에 채워집니다. (아래 LM Studio 안내 참고)
- **작업 파일 내보내기 / 가져오기**: 백업·이관용 JSON 파일입니다.
- 목록에서 **연필**로 수정, **휴지통**으로 삭제합니다. (본인이 작성한 사례 기준)

등록·수정 화면에서 특히 통계와 연결된 항목은 다음과 같습니다.

- **처리기관**: 병원 / 한국의료분쟁조정중재원 / 한국소비자원 / 법원 / 기타 중 선택 (통계 집계에 사용)
- **접수일자**: 비워 두면 통계에서는 최종 수정일을 대신 사용합니다.

본문 항목은 대략 **① 사건 개요 → 분쟁 쟁점 → ③ 의학적 판단 → ④ 결과 → 예방 시사점** 순으로 구성됩니다.

### 사례집 미리보기 · 발행 탭

- 진료과별로 묶인 사례집 형태를 확인합니다.
- **PDF로 저장(인쇄)**: 브라우저 인쇄 대화상자에서 PDF로 저장하면 됩니다.
- **Word 파일로 발행**: `.doc` 파일로 다운로드합니다.

### 통계 탭

- 등록된 사례를 기준으로 **접수 건수**, **배상 발생 건수**(조정결과 등이 입력된 사례), **배상률**을 보여 줍니다.
- **연도 · 진료과 · 처리기관** 필터를 조합해 구간을 좁힐 수 있습니다.
- 연도별·진료과별·처리기관별 건수를 막대 형태로 확인할 수 있습니다.
- 접수일자·처리기관·조정결과 등을 사례에 꾸준히 채워 두면 통계 품질이 좋아집니다.

### FAQ 탭

- 카테고리별로 자주 묻는 질문과 안내 답변을 펼쳐 볼 수 있습니다.
- 상단 검색창에 키워드(예: 보호자, 수술, 외국인 환자)를 입력하면 질문·답변 모두에서 검색합니다.
- **특정 사건에 대한 법률 자문이 아닙니다.** 구체적 판단이 필요하면 법무지원팀(☎7633)으로 문의해 주세요.

### 저장 전 꼭 확인할 것

자동으로 채워진 내용(특히 AI·PDF 불러오기)은 **초안**입니다. 사실관계, 수치, 개인정보 마스킹 여부를 확인한 뒤 저장하세요.

## 로컬 AI(LM Studio) 연동 안내

「PDF에서 AI로 서식 불러오기」는 **선택 기능**입니다. AI를 쓰지 않으면 규칙 기반 정리만으로도 동작하며, AI 서버가 꺼져 있어도 앱 자체(목록·저장·발행·통계·FAQ)는 정상 사용 가능합니다.

### AI가 하는 일과 하지 않는 일

| 하는 일 | 하지 않는 일 |
|---|---|
| 업로드한 PDF 텍스트를 읽어 사례 양식(제목, 진료과, 분쟁 유형, 타임라인, 쟁점 등) 초안을 채움 | 문서 전체를 병원 밖·클라우드 AI로 보내지 않음 |
| 내 PC에서 실행 중인 LM Studio로만 요청 | 저장·검토·발행 결정을 대신하지 않음 |

PDF 본문은 브라우저 → **같은 컴퓨터의** `localhost`(LM Studio)로만 전달됩니다.

### 사용 전 준비 (담당자 PC마다)

AI 불러오기를 쓰려면 **PDF를 올리는 그 PC**에 LM Studio가 설치·실행되어 있어야 합니다. 팀원이 다른 PC에서 목록·통계·FAQ만 보는 경우에는 LM Studio가 필요 없습니다.

1. [LM Studio](https://lmstudio.ai) 공식 사이트에서 프로그램을 설치합니다.
2. 앱 안에서 한국어 문서 정리에 쓸 모델을 검색·다운로드합니다.
   - 예: **EXAONE** 계열 등 한국어에 강한 모델
   - **2.4B 이상**을 권장합니다. 1.2B급 초소형 모델은 지시를 무시하고 JSON이 아닌 긴 설명을 내는 경우가 많아, 이 앱에서는 실패하기 쉽습니다.
   - 커뮤니티가 안전장치를 제거한 **abliterated** 등 비공식 변형은 형식 준수가 떨어져 **권장하지 않습니다**.
3. LM Studio 왼쪽의 **Local Server**(또는 `</>` 서버) 탭에서:
   - 사용할 모델을 선택한 뒤
   - **Start Server**로 서버를 켭니다.
   - 기본 주소는 보통 `http://localhost:1234` 입니다.
4. 이 사례집 앱 화면에서 **톱니바퀴(설정)** 아이콘을 엽니다.
   - 「PDF 불러올 때 AI로 서식 자동 정리 사용」을 **켜고**
   - 서버 주소가 `http://localhost:1234` 인지 확인한 뒤 저장합니다. (대부분 기본값 그대로)

### 사용 순서

1. LM Studio에서 모델 로드 + **서버 시작** 상태를 확인합니다.
2. 사례 관리 탭 → **PDF에서 AI로 서식 불러오기** → PDF 파일 선택
3. 수 분 정도 걸릴 수 있습니다. (PC 성능·모델 크기·문서 길이에 따라 다름)
4. 폼이 열리면 내용을 검토·수정한 뒤 **저장**합니다.

### AI가 실패하거나 느리게 느껴질 때

| 증상 | 확인·대응 |
|---|---|
| 「LM Studio 서버에 연결할 수 없습니다」 | Local Server가 켜져 있는지, 주소가 설정과 같은지, 방화벽이 막지 않는지 확인 |
| 「JSON 대신 문장을 반환」 등 연동 실패 | 더 큰 모델(2.4B+)로 바꾸거나, abliterated가 아닌 정식 계열 모델 사용. 실패 시 앱이 **규칙 기반 정리**로 자동 전환합니다 |
| 응답이 수 분 이상 걸림 | 정상일 수 있음. 문서가 매우 길면 더 오래 걸립니다. 가능하면 GPU를 쓰도록 LM Studio에서 설정 |
| 진료과·분쟁 유형이 비거나 이상함 | 초안 오류일 수 있음. 폼에서 직접 수정 (분쟁 유형은 설명의무·진단지연·수술·투약오류·검사·감염·기타 중 선택) |

### 보안·개인정보 관련 참고

- AI 분석에 쓰는 텍스트는 **해당 담당자 PC 안의** LM Studio로만 갑니다.
- 앱에 저장되는 사례 본문은 팀 공유용 클라우드(Firestore)에 저장되며, 로그인한 팀원에게 보입니다.
- 자동 마스킹은 보조 수단입니다. 이름·연락처 등이 남아 있지 않은지 **저장·발행 전 사람 확인**이 필요합니다.

## 데이터가 어디에 저장되는가

| 데이터 | 저장 위치 |
|---|---|
| 등록된 사례 본문 | 클라우드(Firestore), 로그인한 팀원과 실시간 공유 |
| AI 연동 설정(서버 주소 등) | 사용 중인 브라우저에만 저장 (PC·브라우저마다 다름, 클라우드로 안 감) |
| PDF 원문(AI 분석 시) | 내 PC의 LM Studio로만 전달, 외부 AI 서버로 전송되지 않음 |
| FAQ 안내 문구 | 앱에 포함된 안내 데이터 (사례 본문과 별도) |
| 작업 파일(.json) | 내보내기 시 내 PC 파일로 저장, 사용자가 직접 보관 |

## 알려진 제한사항

- **HWP** 파일은 지원하지 않습니다. 한/글에서 PDF로 저장한 뒤 업로드하세요.
- **스캔만 된 PDF**(글자 선택이 안 되는 이미지 PDF)는 텍스트를 읽지 못해 자동 입력이 어렵습니다.
- 개인정보 마스킹은 패턴(정규식) 기준이라 완벽하지 않습니다. 저장·발행 전 재확인이 전제입니다.
- 로컬 AI 품질·속도는 **모델과 PC 성능**에 크게 좌우됩니다. 저사양 PC에서는 문서 하나 처리에 수 분이 걸릴 수 있습니다.
- 두 사람이 **같은 사례를 동시에 수정**하면, 나중에 저장한 내용이 앞선 내용을 덮어씁니다. (자동 충돌 병합 없음)
- AI가 채운 진료과·분쟁 유형·수치 등은 오류가 있을 수 있으므로 반드시 검토하세요.
- **통계**의 배상 여부는 조정결과·합의금 등 입력 유무를 기준으로 한 1차 집계입니다. 접수일자·처리기관이 비어 있으면 연도·기관 분류가 부정확할 수 있습니다.
- **FAQ**는 일반 정보 제공 목적이며, 개별 사안에 대한 공식 법률 의견이 아닙니다.

상업적 용도로 사용할 수 없으며, **개인 및 기관의 내부 업무용**으로 제한합니다.
